# ⚽ پیش‌بینی بازی‌های فوتبال

برنامه‌ای که به‌طور مداوم اطلاعات بازی‌های پیش رو را جمع می‌کند و بر اساس آن می‌گوید کدام تیم شانس بیشتری برای برد دارد:

- **فرم اخیر**: نتایج ۱۰ بازی آخر هر تیم (همه‌ی رقابت‌ها) با وزن بیشتر برای بازی‌های جدیدتر
- **جدول لیگ**: رتبه، امتیاز، گل زده و خورده، و عملکرد جداگانه در خانه و بیرون
- **مصدومان و محرومان**: بازیکنان غایب یا مشکوک و میزان اهمیتشان برای تیم
- **اخبار تیم‌ها** (اختیاری): جست‌وجوی اینترنتی با Claude برای آخرین اخبار مصدومیت، محرومیت، چرخش بازیکنان و…
- **رویارویی مستقیم**: نتایج دیدارهای قبلی دو تیم (فقط برای اطلاع)

خروجی شامل احتمال برد میزبان / تساوی / برد میهمان، نتیجه‌ی محتمل، میزان اطمینان و دلایل پیش‌بینی است؛ هم در ترمینال و هم در یک داشبورد وب فارسی.

## منابع داده

| داده | منبع | کلید |
|---|---|---|
| برنامه‌ی بازی‌ها، نتایج، جدول، رویارویی مستقیم | [football-data.org](https://www.football-data.org) | رایگان (لازم) |
| مصدومان و محرومان لیگ برتر انگلیس | API عمومی Fantasy Premier League | لازم نیست |
| اخبار تیم‌ها برای همه‌ی لیگ‌ها | Claude + جست‌وجوی وب | `ANTHROPIC_API_KEY` (اختیاری) |

پلن رایگان football-data.org این رقابت‌ها را پوشش می‌دهد: لیگ برتر (`PL`)، لالیگا (`PD`)، سری آ (`SA`)، بوندسلیگا (`BL1`)، لیگ ۱ (`FL1`)، لیگ قهرمانان (`CL`)، اردیویسی (`DED`)، لیگ پرتغال (`PPL`)، چمپیونشیپ (`ELC`)، برزیل (`BSA`) و جام جهانی/یورو.

## نصب

</div>

```bash
git clone https://github.com/BigMoj/bet.git && cd bet
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[news]"        # یا بدون اخبار:  pip install -e .
cp .env.example .env            # سپس کلیدها را در .env وارد کنید
```

<div dir="rtl">

۱. در [football-data.org/client/register](https://www.football-data.org/client/register) ثبت‌نام کنید؛ کلید به ایمیلتان می‌آید. آن را در `.env` جلوی `FOOTBALL_DATA_API_KEY` بگذارید.
۲. (اختیاری) برای تحقیق خبری، کلید API از [console.anthropic.com](https://console.anthropic.com) بگیرید و جلوی `ANTHROPIC_API_KEY` بگذارید. بدون این کلید، برنامه همچنان کار می‌کند و مصدومان لیگ برتر را از FPL می‌خواند.

## استفاده

</div>

```bash
# تحلیل یک بازی (نام فارسی یا انگلیسی؛ اگر بازی در برنامه نباشد، تیم اول میزبان فرض می‌شود)
fp predict "منچستر سیتی" "آرسنال"
fp predict "Man City" Arsenal

# پیش‌بینی همه‌ی بازی‌های امروز و فردا
fp upcoming
fp upcoming --days 7 -c PL -c CL --details

# اجرای مداوم: هر ۶۰ دقیقه همه‌چیز را دوباره بررسی می‌کند + داشبورد روی http://localhost:8000
fp watch --serve
fp watch --interval 30 --days 3 --serve --port 8080

# دقت پیش‌بینی‌های قبلی (بعد از پایان بازی‌ها خودکار ثبت می‌شود)
fp accuracy
```

## مدل پیش‌بینی چطور کار می‌کند؟

۱. برای هر تیم **قدرت حمله و دفاع** نسبت به میانگین لیگ حساب می‌شود؛ ۶۰٪ از آمار خانه/بیرون همین فصل و ۴۰٪ از فرم اخیر. برای اینکه چند بازی اول فصل نتیجه را افراطی نکند، آمار به سمت میانگین «کشیده» می‌شود.
۲. **گل مورد انتظار** هر تیم = میانگین گل لیگ × قدرت حمله‌ی خودش × ضعف دفاعی حریف.
۳. **غایبان** بر اساس پست (مهاجم بیشتر روی حمله، مدافع و دروازه‌بان روی دفاع) و اهمیت بازیکن (دقایق بازی، گل و پاس گل، شاخص ICT، قیمت FPL) گل مورد انتظار را تعدیل می‌کنند.
۴. با توزیع **پواسون** (با اصلاح Dixon-Coles برای نتایج کم‌گل) احتمال تک‌تک نتایج و در نهایت احتمال برد/مساوی/باخت محاسبه می‌شود.

هر پیش‌بینی در `data/predictions.db` ذخیره می‌شود و بعد از پایان بازی نتیجه‌ی واقعی ثبت می‌شود، تا با `fp accuracy` ببینید مدل در عمل چقدر درست می‌گوید (درصد درست، Brier score، log loss).

## تنظیمات (`.env`)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `FP_COMPETITIONS` | `PL,PD,SA,BL1,FL1,CL` | رقابت‌هایی که دنبال می‌شوند |
| `FP_LOOKAHEAD_DAYS` | `2` | چند روز جلوتر بررسی شود |
| `FP_WATCH_INTERVAL_MINUTES` | `60` | فاصله‌ی به‌روزرسانی در حالت watch |
| `FP_RECENT_MATCHES` | `10` | تعداد بازی‌های اخیر برای فرم |
| `FP_NEWS_RESEARCH` | `auto` | `on` / `off` / `auto` (اگر کلید Claude باشد روشن) |

## محدودیت‌ها

- پلن رایگان football-data.org حداکثر ۱۰ درخواست در دقیقه دارد؛ برنامه خودش صبر می‌کند و پاسخ‌ها را کش می‌کند، پس اولین اجرا برای چند بازی ممکن است یکی دو دقیقه طول بکشد.
- اطلاعات مصدومان بدون کلید Claude فقط برای لیگ برتر انگلیس موجود است.
- برای بازی‌های بین دو لیگ مختلف (مثلاً لیگ قهرمانان) مقایسه‌ی قدرت تقریبی است.
- تحقیق خبری با Claude برای هر بازی هزینه‌ی API دارد (نتیجه‌اش ۶ ساعت کش می‌شود).
- فوتبال ذاتاً غیرقابل پیش‌بینی است؛ حتی مدل‌های حرفه‌ای معمولاً حدود ۵۰ تا ۵۵ درصد نتایج را درست حدس می‌زنند. خروجی را به‌عنوان احتمال ببینید، نه قطعیت.
